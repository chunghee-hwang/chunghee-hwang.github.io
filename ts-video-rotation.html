동영상 너비/높이 반대 저장 이슈

FFprobe / MediaConvert / Kotlin / Python

작업 기간

2025년 4월 21일 (1일)

현상

  • 720x1280 세로 영상을 업로드하면 DB에 width: 1280, height: 720으로 반대로 저장되는 이슈
  • 게재위치 제한과 영상 크기가 동일한데 400 에러 발생
  • 항상 발생하는 것은 아님 - 특정 조건에서만 발생

원인 분석

스마트폰 영상의 메타데이터 특성

스마트폰으로 세로 영상을 찍으면 메타데이터에는:

  • width: 1280, height: 720 (가로 기준)
  • rotate: 90 (회전 정보)

즉, width/height는 그대로이고 rotate 값만 바뀌는 경우가 있습니다.

FFprobe로 메타데이터 확인

# 회전 값 확인 ffprobe -v error -select_streams v:0 \ -show_entries stream_tags=rotate \ -of default=noprint_wrappers=1:nokey=1 파일명.mp4 # 가로 세로 확인 ffprobe -v error -select_streams v:0 \ -show_entries stream=width,height \ -of csv=p=0 파일명.mp4

문제: 기존 코드는 rotate 메타데이터를 고려하지 않고 width/height를 그대로 저장했습니다.

해결책 1: 너비/높이 보정

회전 각도에 따른 너비/높이 스왑

// VideoMetaService.kt private fun extractVideoWidthHeight(stream: Stream): Pair<Int, Int> { val rotation: Double = getRotation(stream) // 90도 또는 270도 회전이면 가로/세로 바꿔치기 val shouldSwapWidthHeight = abs(rotation) == 90.0 || abs(rotation) == 270.0 val width = if (shouldSwapWidthHeight) stream.height else stream.width val height = if (shouldSwapWidthHeight) stream.width else stream.height return width to height } private fun getRotation(stream: Stream): Double { val rotation: String? = stream.getTag("rotate") return rotation?.toDoubleOrNull() ?: 0.0 }

추가 문제 발생

너비/높이 보정 후 새로운 문제가 발생했습니다:

  • MediaConvert로 인코딩 시 rotate 값이 그대로 적용되어 영상이 눕혀버림
  • 예: 720x1280으로 저장했는데, 720x1280 사각형 안에서 90도 회전된 영상이 출력

해결책 2: MediaConvert 역회전

회전 각도를 DB에 저장하고 역회전 적용

# mediaconvert-request.py def specify_rotation(job_settings, args): source_rotation = args.rotation # AUTO로 지정하면 메타데이터의 회전 각도만큼 역회전 # 예) 시계방향 90도 회전 → -90도로 역회전 is_rotated = source_rotation != 0 and source_rotation % 90 == 0 target_rotation = 'AUTO' if is_rotated else 'DEGREE_0' for input_item in job_settings.get('Inputs', []): input_item.setdefault('VideoSelector', {}) input_item['VideoSelector']['Rotate'] = target_rotation return job_settings

변경 사항

  • DB에 회전 각도 저장 (media_content_resources 테이블)
  • MediaConvert 요청 시 회전 각도가 90, 180, 270도면 AUTO로 설정
  • AUTO는 메타데이터 기준으로 역회전 수행

결과: 인코딩된 영상이 90도 회전되지 않고 똑바로 출력됩니다. 너비/높이도 정확하게 저장됩니다.

교훈

  • 스마트폰 영상은 실제 화면 방향과 메타데이터의 width/height가 다를 수 있습니다.
  • 영상 처리 시 rotate 메타데이터를 반드시 고려해야 합니다.
  • 문제 해결 시 연쇄적으로 발생하는 부작용을 예측하고 대응해야 합니다.
  • MediaConvert의 Rotate 옵션을 활용하면 자동으로 역회전 처리가 가능합니다.
