Airflow Scheduler Redis 모듈 에러

2024.10
Airflow / Celery / Redis / Kubernetes

작업 기간

2024년 10월 (발생: 2024-07-20, 2024-09-25, 2024-09-26, 2024-11-14)

현상

  • 대부분의 DAG들이 정상 가동되지 못하는 현상 발생
  • 불규칙적으로 발생하며, 특정 조건에서만 나타남:
    • Airflow 레포에 코드 변경으로 git-sync가 이뤄졌을 때
    • Terraform으로 Airflow 환경 변수 수정 후 apply하여 파드가 재시작되었을 때
ERROR - Error sending Celery task: module 'redis' has no attribute 'client' Celery Task ID: TaskInstanceKey(dag_id='nestads-invitation-expired', ...) ... File "kombu/transport/redis.py", line 282, in <module> class PrefixedRedisPipeline(GlobalKeyPrefixMixin, redis.client.Pipeline): AttributeError: module 'redis' has no attribute 'client'

원인 분석

에러 로그 분석

에러는 Celery가 Redis 브로커에 연결하려 할 때 발생했습니다. kombu/transport/redis.py에서 redis.client.Pipeline을 참조하는데, redis 모듈에서 client 속성을 찾지 못하는 문제였습니다.

문제 코드 위치

# /home/airflow/.local/lib/python3.9/site-packages/kombu/transport/redis.py class PrefixedRedisPipeline(GlobalKeyPrefixMixin, redis.client.Pipeline): """Custom Redis pipeline that takes global_keyprefix into consideration.""" def __init__(self, *args, **kwargs): self.global_keyprefix = kwargs.pop('global_keyprefix', '') redis.client.Pipeline.__init__(self, *args, **kwargs)

근본 원인

Airflow 2.8.4 버전에서 발생하는 알려진 이슈로, 2.9.4 버전에서도 동일하게 발생합니다. Python의 redis 모듈과 kombu 라이브러리 간의 호환성 문제로 추정됩니다.

참고: Apache Airflow GitHub Issue #41359에서 동일한 문제가 보고되어 있으며, 아직 해결 중인 상태입니다.

재현 시도

로컬 환경에서 Docker Compose로 동일한 Airflow, Redis 버전을 구성하여 재현을 시도했습니다:

  • Redis 컨테이너를 임시로 중지해본 결과, 비슷하지만 다른 에러가 발생
  • 정확한 재현 조건을 찾지 못함 - 불규칙적 발생이 특징

해결책

자동 복구 스크립트 배포

해당 에러 발생 시 스케줄러를 자동으로 재시작하는 스크립트를 Kubernetes에 배포했습니다.

임시 해결 방법

에러 발생 시 수동으로 airflow-scheduler StatefulSet을 통해 redeploy:

kubectl rollout restart statefulset airflow-scheduler -n airflow

결과: 자동 복구 스크립트 배포 후 에러 발생 시에도 빠르게 정상화되어 DAG 실행 중단 시간이 크게 감소했습니다.

교훈

  • 오픈소스 라이브러리 간 버전 호환성 문제는 예측하기 어려우므로, 모니터링과 자동 복구 체계가 중요합니다.
  • 불규칙적으로 발생하는 이슈는 완벽한 해결보다 빠른 복구에 초점을 맞추는 것이 현실적입니다.
  • Kubernetes 환경에서는 Pod 재시작을 자동화하여 장애 대응 시간을 단축할 수 있습니다.
