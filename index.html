About Me

사용자와 운영자의 관점 모두를 고려하며, 시스템의 안정성과 실용성을 함께 추구하는 개발자입니다. 백엔드 개발을 중심으로 DevOps와 데이터 인프라까지 아우르는 실무 경험을 쌓아왔습니다.

개발을 할 때 "이 기능은 실제로 어떻게 운영될까?", "문제가 생겼을 때 가장 먼저 불편함을 겪을 사람은 누구일까?"를 항상 고민합니다. 단순히 코드를 잘 짜는 것을 넘어서, 서비스가 지속적으로 잘 동작할 수 있도록 만드는 일이 진짜 개발자의 역할이라고 믿습니다.

팀 내에서는 API 설계, DB 모델링, 메시지 큐 구성 등 서비스의 뼈대를 만드는 역할을 맡으며, 기술 스택 선정과 구조 설계 방향 논의에서 적극적으로 의견을 제시합니다. 배포 자동화, 장애 대응 스크립트 작성, 모니터링 시스템 구축 등 개발과 운영 사이의 연결도 주도해왔습니다.

Hibernate 6 마이그레이션 성능 최적화

2026.05

Spring Boot 3.2.2 마이그레이션 후 광고 송출 동기화 API의 응답 시간이 prod 기준 1,500ms에서 4,000ms로 약 2.6배 저하된 문제를 해결. 원인은 Hibernate 6 SQM 엔진이 컬렉션 fetchJoin의 Cartesian Product를 처리하는 비용이 급증한 것으로, 33개 테이블 한방 쿼리를 ID 조회 → 엔티티 로딩 2단계로 분할하고 컬렉션은 Hibernate.initialize() + batch fetch로 지연 초기화하여 prod 응답 시간 ~500ms 달성(SB2 대비 약 3배 빠름). 배포 후 RDS CPU 사용량 45% → 20%로 감소.
